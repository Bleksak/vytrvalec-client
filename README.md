# Měsíční Vytrvalec klient

Web application Měsíční Vytrvalec availiable [here](https://vytrvalec.kts.zcu.cz/)

## Prerequisities

- Node >=22

## Set up

- Install dependencies using `yarn` (or `npm install` or `pnpm install`)
- Create `.env` file from `.env.example` and fill it with necessary information. Especially `VITE_API_BASE`

## Run

- In terminal run `yarn dev` (or `npm run dev`...)

### Building

To create a production version of your app:

- In terminal run `yarn build` (or `npm run build`...)
